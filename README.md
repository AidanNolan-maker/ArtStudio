# ArtStudio

ArtStudio is a Java desktop drawing application built with JavaFX.

## Technology Stack

- Java 21
- JavaFX
- SQLite
- JDBC
- Maven
- JUnit 5

## Planned Features
- Freehand drawing
- Custom brush colors and sizes
- Eraser and undo/redo
- Save and reopen artwork
- SQLite-backed artwork gallery
- PNG image export

## Running the Application

On Windows, run:

`.\mvnw.cmd clean javafx:run`

## Running Tests

On Windows, run:

`.\mvnw.cmd test`
